# 메이플스타 문의 접수 보조 AI

공식 접수 시스템에 붙이는 기능을 가정한 비공식 포트폴리오입니다. 환불·아이템 복구 문의에서 필요한 조건을 확인하고 공식 자료 기반 안내부터 담당자용 정보 정리·모의 접수까지 연결합니다.

## 시연

예시 문의 선택 또는 직접 입력 → 조건 확인·정책 안내 → 자동 정리한 문의 확인(필요 시 수정) → 가상 UID·프로필 입력 → 저장 동의·모의 접수 → 담당자 접수함 확인.

- 실제 공식 서비스와 연동하지 않으며 계정 조회·환불·복구를 실행하지 않습니다.
- 가상 계정 정보만 사용해 주세요. 개인정보·비밀번호·인증번호는 채팅에 입력하지 마세요.
- 채팅 문의는 Google Gemini로 전달됩니다. 별도 계정 입력 양식은 모델 요청과 분리됩니다.
- 모의 접수함은 현재 세션에만 보관하며 영속 저장소가 아닙니다.

## 배포

Streamlit Community Cloud: Python 3.12, 실행 파일 app.py, requirements.txt 사용.

Cloud의 Advanced settings → Secrets에 아래 형식으로 설정합니다. 키는 저장소에 넣지 않습니다.

```toml
GEMINI_API_KEY = "발급받은 키"
GEMINI_MODEL = "gemini-3.5-flash-lite"
```

첫 문의 처리 시 로컬 다국어 임베딩 모델을 내려받고 검색 색인을 자동 준비합니다. Cloud 재시작으로 임시 저장소가 지워지면 다시 준비할 수 있습니다. 첫 실행은 일반 응답보다 오래 걸릴 수 있습니다. Gemini 무료 할당량과 Cloud 자원 제한을 받습니다.

## 구조·한계

Streamlit → LangGraph 문의 분류·조건 확인 → 공식 문서 선별·Chroma 검색 → Gemini 안내 생성 → 사용자 확인·모의 접수. 인용 실패 시 추가 생성 요청 없이 검증 실패를 안내합니다. 수집 자료·정책은 최신성을 보장하지 않으며 개별 처리 가능 여부는 담당자 기록 확인이 필요합니다.

이전 QA에서 조건 왜곡을 발견하고 고객 원문 구절 검증, 수정 본문 우선 처리, 모름 상태 보존을 보완했습니다. 조건 왜곡 3개 사례는 실제 모델 검사에 통과했지만 일반적인 정확도나 업무 시간 절감 효과로 해석하지 않습니다.

자료 출처와 범위: [출처 기록](docs/data_sources.md). 원문 권리는 각 제공자에게 있습니다.
