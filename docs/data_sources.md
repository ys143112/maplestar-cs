# 데이터 출처와 이용 조건 기록

기준일: 2026-10-23. 공식 공개 자료를 교육용 검색 근거로 사용한 비공식 프로젝트다. 원문 권리는 각 제공자에게 있다.

| 출처 | 포함 자료 | 사용 범위·상태 |
|---|---|---|
| https://maplestar.io | 정책·공지·업데이트·가이드 203건 | 공개 HTML 스냅샷. URL·수집/게시/수정 시각·본문 해시 보존. 정책 적용/개정 관계 unknown이 남아 있음 |
| https://m.nexon.com/terms/699 | 플랫폼 크리에이터 환불 관련 1건 | 플레이어 카드/현금 환급이나 게임 교환권 정책으로 일반화하지 않음 |
| https://maplestoryworlds-creators.nexon.com/ko/docs?postId=835 | 플랫폼 미지급 관련 1건 | 크리에이터 대상 자료임을 구별하고 플레이어에게 운영자 기능을 요구하지 않음 |
| sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 | 로컬 다국어 임베딩 모델 | 원본 Apache-2.0 모델. FastEmbed/Qdrant 경량 ONNX 사용. 모델 파일은 저장소에 포함하지 않음 |

robots·수집·검토·제외 사유 기록은 cs_references_collection.json, official_topics_collection.json, official_guides_collection.json 등에 있다. 공개 접근 가능·robots 허용은 원문 일괄 재배포 허가와 다르다. 외부 재배포 허용을 확보했다고 주장하지 않으며 교육 제출/공개 배포 범위는 별도로 확인해야 한다. GitHub 공개 배포는 이번 GitLab 제출과 분리한다.

실시간 수집은 공식 공개 news·policy 주소에만 접근하고 로그인·비공개 API·고객 문의·댓글·계정 정보를 수집하지 않는다. 이미지 포함 신규 본문은 자동 판독하지 않고 제한 안내를 제공한다. User-Agent 식별과 robots, 최소 1.2초 간격·timeout·자동 재시도 없음 규칙을 적용한다. 필요한 연락처는 SOURCE_CONTACT로 운영자가 설정한다.

데모 문의·계정 값은 가상 데이터를 사용한다. 계정 식별자와 회신 이메일은 색인 코퍼스에 넣지 않는다. API 키·Secrets·접수 세션 기록은 교육 제출 데이터가 아니다. 프로젝트 명세 원본 PDF와 개인 지침도 저장소에 복사하지 않는다.
